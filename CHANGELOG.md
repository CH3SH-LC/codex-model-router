# Changelog

## 1.2.0 — 2026-10-20

First public preview.

- In-app provider/model settings, native plugin settings, and sidebar/chat entrypoints.
- Subscription routing plus custom Responses / Chat Completions adapters.
- DPAPI key storage, revision checks, loopback access capability, selective restore.
- Real desktop panel acceptance and engine/tool-loop validation with bounded claims.
- Portable Windows plugin installation with versioned Python environments.
- MIT license, contributor/security/privacy documentation, Windows CI, and
  allowlisted source packages with SHA-256 verification.

## 1.1.2 — local validation build

Validated the application-owned plugin, streaming completion records, UTF-8 MCP
transport, desktop lifecycle observation, and in-app UI. This build was not an
upstream public release.
